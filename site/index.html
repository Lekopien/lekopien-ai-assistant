An AI assistant with no API key

A customer-support chatbot built from first principles. It classifies what you want with a Naive Bayes model and finds the best answer with TF-IDF vector search. Everything runs right here in your browser.

How it works

1. Tokenize

Lowercase, drop stop-words and strip suffixes so "sites" and "site" match.

2. Classify intent

Multinomial Naive Bayes with Laplace smoothing scores every intent and turns log-probabilities into a confidence.

3. Retrieve

TF-IDF vectors and cosine similarity pick the closest answer from the knowledge base.

4. Fall back

Below a similarity threshold it admits it doesn't know. With a local Ollama model it can write free-form answers too.
